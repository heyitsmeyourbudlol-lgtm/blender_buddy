# Blender 4.0+ API gotchas (do NOT use pre-4.0 names)
Principled BSDF (`ShaderNodeBsdfPrincipled`) sockets were renamed in 4.0. Using the old names causes KeyError at runtime. Always use the new names:
- `Subsurface` → `Subsurface Weight`  (old `Subsurface Color` was removed)
- `Specular` → `Specular IOR Level`
- `Sheen` → `Sheen Weight`
- `Clearcoat` → `Coat Weight` ; `Clearcoat Roughness` → `Coat Roughness` ; `Clearcoat Normal` → `Coat Normal` ; `Clearcoat Tint` → `Coat Tint`
- `Transmission` → `Transmission Weight`  (old `Transmission Roughness` was removed)
- `Emission` is now split into `Emission Color` (RGBA) + `Emission Strength` (float).
When unsure about any socket / property / enum name on any node, call search_api for the RNA type first — do not write code from memory.

# Action Mode code idioms
Selection / active pair: `obj.select_set(True)` + `bpy.context.view_layer.objects.active = obj`. `bpy.ops` that touch "the active object" fail silently if active isn't also selected.
Keyframes: `obj.keyframe_insert(data_path='location', frame=f)` (optional `index=0|1|2`). New action: `act = bpy.data.actions.new('Move'); obj.animation_data_create(); obj.animation_data.action = act`.
Modifiers: `mod = obj.modifiers.new(name='Bevel', type='BEVEL')` then set attrs (`mod.width = 0.1`). Do NOT use `bpy.ops.object.modifier_add` in scripts — it depends on viewport context and fails.
Materials & nodes: `mat = bpy.data.materials.new('M'); mat.use_nodes = True; nt = mat.node_tree`. Mutate existing nodes; clear only when rebuilding. Socket lookup is by name — see the Principled rename table above.
Linking + parenting: `bpy.data.meshes.new` + `bpy.data.objects.new` does NOT put the object in the scene — you must `bpy.context.collection.objects.link(obj)`. Parent: `child.parent = parent`, then `child.matrix_parent_inverse = parent.matrix_world.inverted()` to avoid a jump.
bmesh vs edit-mode ops: for batch vertex/edge/face edits, use `bmesh.new()` off `obj.data` (or `bmesh.from_edit_mesh(obj.data)` in EDIT mode), then `bm.to_mesh(me)` / `bmesh.update_edit_mesh(me)`. Avoid `bpy.ops.mesh.*` in scripts — they need EDIT-mode viewport context.
Lights & cameras: data lives on `.data`: `light.data.energy`, `light.data.color`, `light.data.type = 'AREA'`, `cam.data.lens`, `cam.data.sensor_width`. Type-specific props (e.g. `shadow_soft_size` on POINT) only exist on matching light types.
Geometry nodes: `mod = obj.modifiers.new('GN', 'NODES'); mod.node_group = bpy.data.node_groups['X']`. Pass inputs via the modifier's socket IDENTIFIERS (`mod["Input_N"] = v`), NOT socket names — identifiers come from `mod.node_group.interface.items_tree`.
Context overrides for ops that need a specific area/region: `with bpy.context.temp_override(area=a, region=r): bpy.ops.view3d.view_all()`. Never invoke viewport ops blindly from the Script Editor.
Evaluated / post-modifier data: `deps = bpy.context.evaluated_depsgraph_get(); obj_eval = obj.evaluated_get(deps); me_eval = obj_eval.to_mesh()` — free with `obj_eval.to_mesh_clear()`.
