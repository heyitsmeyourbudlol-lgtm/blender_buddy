# Agent mini apps

Single-purpose scripts agents build for themselves when repetition beats manual work.

- **Charter:** `notes/AGENT_MINI_APPS.md`
- **Scaffold:** `./scripts/peer mini-apps --scaffold --name my_tool --purpose "..."`
- **Run:** `python3 scripts/agent_tools/my_tool.py --help`
- **Promote:** when the team repeats the loop → Command Builder (`notes/COMMAND_BUILDER.md`)

Do not add secrets, new pip deps, or cross-niche orchestration here.
