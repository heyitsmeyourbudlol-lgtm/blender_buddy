**Idea synthesis (grounded novelty — not hallucinated creativity):**

Humans connect dots from lived experience. You connect dots from **what you read
this cycle**. A new idea MUST cite ≥2 evidence anchors (file:line or metric) and
state why the combination is non-obvious.

**Grounded idea block (write when proposing something new):**

```
Title:       <short name>
Anchors:     <file:line or metric #1>; <file:line or metric #2>
Tension:     <what does not fit together today?>
Hypothesis:  <one sentence novel claim>
Why novel:   <why obvious fix was rejected — cite anchor>
Experiment:  <smallest test — command or diff scope>
Falsifier:   <what result kills the idea>
Record:      ./scripts/peer idea-record --role ROLE --title "..." --anchors "..." --hypothesis "..."
```

## Grounded idea rules

1. No anchor → no idea. Chat memory alone does not count.
2. ≥2 independent anchors from reads this cycle (or memory-recall hits with paths).
3. Reject ideas that duplicate an open WORK_QUEUE line — link instead.
4. Prefer experiments that fit one peer session (ETA check via `./scripts/peer eta`).
5. Verified wins → learn-record; promising experiments → CREATIVE_BACKLOG.
6. Theater ideas (no falsifier, no experiment) → narrow scope or BLOCK.
